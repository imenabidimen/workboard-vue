# WorkBoard — Vue 3

A responsive project-management frontend designed to consume the TaskForge NestJS API.

**Stack:** Vue 3, TypeScript, Vite, Pinia, Vue Router, Vitest.

## Features
- Login flow and protected routes
- Pinia authentication state
- Dashboard task workflow
- Loading/empty/error-friendly UI states
- Component-level validation tests
- API integration boundary ready for TaskForge

## Run
```bash
npm install
npm run dev
npm test
```
